# Declaration of Independence in Akoma Ntoso

The U.S. Declaration of Independence in Akoma Ntoso XML, with a CSS stylesheet that renders the document in the style of the 1823 Stone engraving in a web browser. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `declaration-of-independence.xml` | The Akoma Ntoso document |
| `declaration-of-independence.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Document type:** The Declaration is a `<statement>`, because it is an official document of a body but is not structured as an act.
- **Structure:** The `<preface>` holds the date line and title. The `<preamble>` holds the causes and principles. The `<mainBody>` holds the grievances, the appeals to the British people and the declaration itself.
- **Grievances:** The 27 grievances are 18 `grievance` containers, with the nine "For..." charges nested as `particular` containers under "He has combined with others...". This grouping is an editorial reading; the original has no numbering.
- **Signatures:** The 56 signatures are base64-encoded PNG images embedded in `<img>` elements within `<signature>`, grouped by state in `<conclusions>`. Each has a `<person>` element with the signer's name. Massachusetts and New Hampshire are each kept as one group, although the transcription lists them twice.
- **Rendering:** Browsers do not draw Akoma Ntoso `<img>` elements, so the CSS repeats the signature images as backgrounds. The two heading lines are engraved images placed over live text. State names are in the XML but hidden on the page, because the engraving does not show them.

## Sources

- Text: the U.S. National Archives [transcription](https://www.archives.gov/founding-docs/declaration-transcript) of the Stone engraving. Spelling and capitalization follow that transcription, and its double hyphens are set as em dashes.
- Signatures and heading lines: a high-resolution scan of the Stone engraving. The National Archives offers [high-resolution downloads](https://www.archives.gov/founding-docs/downloads) of the engraving.

## Fonts

The stylesheet embeds Pinyon Script and UnifrakturCook, both licensed under the [SIL Open Font License](https://openfontlicense.org/). The fonts approximate the engraved hand; they do not reproduce it, and line breaks differ from the original.
